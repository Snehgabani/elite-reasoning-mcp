# Support

Use the right channel so reports stay actionable:

- Bugs: https://github.com/Snehgabani/elite-reasoning-mcp/issues/new/choose
- Feature ideas and design discussion: https://github.com/Snehgabani/elite-reasoning-mcp/discussions
- Security vulnerabilities: https://github.com/Snehgabani/elite-reasoning-mcp/security/advisories/new
- Package install page: https://pypi.org/project/elite-reasoning-mcp/

For the fastest bug triage, include:
- `elite-reasoning-mcp` version
- Python version
- MCP client or IDE
- Operating system
- Minimal reproduction steps
- Relevant `uv run python scripts/release_check.py` output if using a checkout
- Whether persisted memory or context injection is involved

Do not include secrets, private code, or raw sensitive memory content.
